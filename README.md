# Codex Apócrifo

Biblioteca interactiva de textos apócrifos y antiguos: María y Jesús, Enoc, textos sumerios y mesopotámicos, ángeles y seres de otros mundos, y las teorías modernas sobre un Jesús extraterrestre, cada una con su contexto crítico.

- `index.html`: el sitio completo (HTML, CSS y JavaScript en un solo archivo).
- `textos/`: los textos completos en formato JSON (`id.json` en inglés, `id.es.json` en español).

Todos los textos completos son traducciones de dominio público o traducciones propias hechas a partir de ellas. Los libros modernos con derechos de autor solo aparecen resumidos.
